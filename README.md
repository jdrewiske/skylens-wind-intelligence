# SkyLens — Wind Intelligence for Outdoor Athletes

A responsive, clickable landing-page concept for a wind-awareness add-on designed around Meta Glasses. The page includes animated wind vectors and flow trails over landscape imagery, sport-specific preview modes, a mobile navigation menu, and a demo waitlist form.

## Run locally
Open `index.html` in a modern browser. No build step is required.

## Interactive features
- Animated wind vectors and moving flow trails over the landscape preview
- Pause/resume flow and toggle vectors on/off
- Cycle between Golf, Tennis, and Outdoor athlete modes
- Interactive modal preview with the same moving wind visualization
- Responsive mobile navigation and email input validation

## Important notes
- Wind speeds, directions, and gusts are illustrative sample values, not live weather data.
- The waitlist form is front-end only. It does not send or store email addresses. Connect it to a mailing-list provider before launch.
- The $0.99/month price is a concept and is not an active subscription offer.
- SkyLens is an independent concept project and is not affiliated with or endorsed by Meta.
- The page loads landscape imagery from Unsplash and needs an internet connection for those images.
